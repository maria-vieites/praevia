# Praevia

Praevia is an OSINT-based reconnaissance assistant designed to support the passive information gathering phase of web application security assessments.

Rather than identifying vulnerabilities directly, Praevia collects, correlates and organises publicly available information about a target, enriches it with vulnerability intelligence, and generates investigation-oriented findings to help security professionals prioritise subsequent manual analysis.

## Objectives

Praevia is designed to support the initial reconnaissance phase of a web application security assessment by:

- Discovering publicly observable assets associated with a target.
- Identifying technologies and their versions.
- Recovering historical web resources.
- Gathering publicly observable Internet exposure information.
- Enriching detected technologies with vulnerability intelligence.
- Correlating observations from different sources.
- Generating investigation-oriented findings.
- Prioritising findings according to their usefulness for subsequent manual investigation.

Praevia is intentionally focused on passive reconnaissance and does not attempt to replace active security testing.

## Scope

Praevia operates within the following boundaries:

- Passive OSINT reconnaissance.
- Publicly available information sources.
- Asset and technology discovery.
- Historical web surface discovery.
- Public Internet exposure intelligence.
- Vulnerability intelligence enrichment.
- Cross-source correlation.
- Investigation-oriented prioritisation.

Praevia does **not** perform:

- Port scanning.
- Active crawling.
- Exploitation.
- Vulnerability validation.
- Brute-force attacks.
- Active service enumeration.
- Risk assessment based solely on passive observations.

The priorities generated by Praevia represent the relative convenience of investigating a finding during subsequent pentesting activities. They do not constitute a definitive assessment of vulnerability severity or security risk.

## Architecture

Praevia follows a modular architecture organised around the different stages of the reconnaissance workflow.

    Target
      │
      ▼
    Collectors

      └── Internet Exposure
              │
              ▼

              │

## Installation

Install the required dependencies with:

    pip install -r requirements.txt

## Usage

Run Praevia against a target:

    python main.py example.com

By default, Praevia launches the interactive command-line interface.

To generate a JSON report instead:

    python main.py example.com --output json

The output directory can be specified with:

    python main.py example.com --output json --output-dir reports/

### Command-line options

    -v, --verbose
        Display additional execution information.

    -q, --quiet
        Suppress the interactive interface.

    -o, --output
        Generate one or more supported report formats.

    --output-dir
        Specify the output directory.

    --no-banner
        Disable the startup banner.

    --version
        Display the current version.
