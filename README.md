# Praevia

Praevia is an OSINT-based reconnaissance assistant designed to support the passive information gathering phase of web application security assessments.

Rather than identifying vulnerabilities, Praevia collects, correlates and organises publicly available information about a target, enriches it with vulnerability intelligence, and generates investigation-oriented reports to help security professionals prioritise subsequent manual analysis.

## Features

- Passive technology fingerprinting
- OSINT data collection and correlation
- Vulnerability intelligence enrichment
- Modular collector architecture
- Investigation prioritisation
- Multiple report formats (HTML, PDF, JSON and TXT)
